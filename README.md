# MuliOS

MuliOS (Multi Usage Linux Interface) is a custom Linux distribution built to adapt to different use cases.

Instead of being focused on one purpose, MuliOS is designed to optimize itself based on what the user needs, such as gaming, development, productivity, or everyday use.

## Base

MuliOS is currently built using:

* Xubuntu
* KDE Plasma

## Goals

* Create a flexible Linux distribution
* Support multiple usage profiles
* Improve performance based on user needs
* Keep the system simple, clean, and customizable
* Improve system security

## Planned Features

* Setup wizard with profile selection
* Usage-based system optimization
* Custom performance profiles
* Future kernel optimization

## Status

MuliOS is currently in early development.

Main focus:

* Building the base system
* Creating installable ISOs
* Developing the setup and optimization system

## How our custom kernel adaptation works

At setup, you will be granted the choice to choose a profile based on your needs.
after selecting an option, you will begin to download an update package from this github repo straight to your computer.
note that this feature is reversible, and could maybe be unstable if not used properly.
